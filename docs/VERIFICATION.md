# Что проверяется

[Релизная сборка 0.4.3](https://github.com/Georgy-hook/GeoRoute/actions/runs/42260390593) прошла тесты клиента, установку, обновление, запуск и удаление в Windows VM.

Проверки GitHub Actions охватывают DNS-протокол Bridge, восстановление, профили ChatGPT/Gemini, региональный выбор, запуск GUI и автозапуск.

Тест установщика в одноразовой Windows VM проверяет установку в путь с кириллицей и пробелами, совпадение файлов с ZIP, запуск GUI через команду ярлыка, запрет обновления работающего приложения, сохранение профилей при обновлении/повторной установке, удаление и очистку своего автозапуска. Установка и удаление не должны менять hosts, DNS или прокси.

Отдельная [проверка опубликованного релиза](../.github/workflows/verify-windows-release.yml) скачивает MSI и ZIP прямо из GitHub Releases, сверяет SHA-256 с GitHub, файлами `.sha256` и отчётом безопасности в теге. Релизные файлы не пересобираются. Дополнительно проверяются стандартная папка `%LOCALAPPDATA%\Programs\GeoRoute`, ярлыки рабочего стола и меню «Пуск», запись в списке установленных приложений и её удаление. Для теста обновления создаётся только временный пакет следующей версии с тем же содержимым; он не публикуется.

**Историческая проверка MSI 0.4.2, 06.11.2026:** [результат проверки точных опубликованных файлов](https://github.com/Georgy-hook/GeoRoute/actions/runs/42213482660).

Текущий снимок [добавления профиля](images/add-profile.png) экспортирован WPF-кодом GeoRoute 0.4.3: в ней одна форма GeoHide для обоих сервисов. Снимки установленной 0.4.2 сохранены в [проверке опубликованной версии](https://github.com/Georgy-hook/GeoRoute/actions/runs/42210022722). Режим экспорта использует чистые настройки и не выполняет сетевых действий; снимки не служат доказательством подключения.

Bridge проверяется через настоящий Windows Service Control Manager под LocalService: запуск, остановка, перезапуск, ошибка запуска и восстановление. Тест не меняет DNS сетевых адаптеров и не выполняется на компьютере пользователя.

Установка Bridge проверяет обычное разрешение имён через DNS Windows. Совпадение правил в кабинете NextDNS с адресами GeoHide оценивается отдельно: ошибка такого правила или ограничение Google не должны откатывать исправный DNS. При тайм-ауте или пустом ответе проверка установки по-прежнему завершается ошибкой.

Успешная проверка сервера в приложении подтверждает ответ на проверочный запрос в этот момент. Она не гарантирует загрузку любого вложения, прохождение авторизации, отсутствие CAPTCHA или работу управления компьютером Dot. Полную перезагрузку компьютера пользователя CI не заменяет.

Для Gemini проверяются HTTPS страницы/API и общая цепочка Google через одно HTTP/2-соединение. TLS проверяет сертификат Gemini; перед запросом Google проверяется, что тот же сертификат покрывает точное имя www.google.com. Проверка привязана к физическому интерфейсу, ограничивает время, размер ответа и число перенаправлений, принимает только два точных Google-имени. Cookie не сохраняются и не копируются из браузера. Страница HTTP 200 подтверждает сетевой маршрут; вход в аккаунт и ответ модели проверяются отдельно. Отдельное TLS-соединение www не требуется для успешно проверенного общего маршрута. Неудачный Google-маршрут не отключает рабочий ChatGPT, но показывается как ограничение Gemini.

HTTP/2 использует закреплённые чистые Python-пакеты h2, hpack и hyperframe из PyPI. Их wheel-файлы с лицензиями включены в пакет; SHA-256 проверяются при запуске и сборке. На компьютере пользователя зависимости не скачиваются. Новые EXE-обёртки не добавляются.

Целостность локальных ссылок, изображений и якорей Markdown проверяет `python tools/check_docs.py`; эта проверка включена в CI. Ссылки старых релизов на инструкции закреплены за соответствующими тегами.

VirusTotal привязан к точным хешам файлов. Смотрите [проверки безопасности](security/README.md); результаты старой версии не распространяются на новый установщик. Отсутствие обнаружений не является гарантией безопасности.
