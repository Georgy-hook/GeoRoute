# Что проверяется

Проверки GitHub Actions охватывают DNS-протокол Bridge, восстановление, профили ChatGPT/Gemini, региональный выбор, запуск GUI и автозапуск.

Тест установщика в одноразовой Windows VM проверяет установку в путь с кириллицей и пробелами, совпадение файлов с ZIP, запуск GUI через команду ярлыка, запрет обновления работающего приложения, сохранение профилей при обновлении/повторной установке, удаление и очистку своего автозапуска. Установка и удаление не должны менять hosts, DNS или прокси.

Отдельная [проверка опубликованного релиза](../.github/workflows/verify-windows-release.yml) скачивает MSI и ZIP прямо из GitHub Releases, сверяет SHA-256 с GitHub, файлами `.sha256` и отчётом безопасности в теге. Релизные файлы не пересобираются. Дополнительно проверяются стандартная папка `%LOCALAPPDATA%\Programs\GeoRoute`, ярлыки рабочего стола и меню «Пуск», запись в списке установленных приложений и её удаление. Для теста обновления создаётся только временный пакет следующей версии с тем же содержимым; он не публикуется.

**MSI 0.4.2 прошёл этот полный цикл 06.11.2026:** [результат проверки точных опубликованных файлов](https://github.com/Georgy-hook/GeoRoute/actions/runs/42213482660).

Текущий снимок [добавления профиля](images/add-profile.png) экспортирован WPF-кодом из версии разработки: в ней одна форма GeoHide для обоих сервисов. Снимки установленной 0.4.2 сохранены в [проверке опубликованной версии](https://github.com/Georgy-hook/GeoRoute/actions/runs/42210022722). Режим экспорта использует чистые настройки и не выполняет сетевых действий; снимки не служат доказательством подключения.

Bridge проверяется через настоящий Windows Service Control Manager под LocalService: запуск, остановка, перезапуск, ошибка запуска и восстановление. Тест не меняет DNS сетевых адаптеров и не выполняется на компьютере пользователя.

Успешная проверка сервера в приложении подтверждает ответ на проверочный запрос в этот момент. Она не гарантирует загрузку любого вложения, прохождение авторизации, отсутствие CAPTCHA или работу управления компьютером Dot. Полную перезагрузку компьютера пользователя CI не заменяет.

Для Gemini отдельно проверяются HTTPS страницы, API и Google www на том же IP с проверкой сертификатов. Перенаправление без доступной страницы проверки не считается рабочим путём CAPTCHA. Общий профиль может подключить рабочий ChatGPT с явным предупреждением о Gemini. Ответ страницы, успешный TLS или ожидаемый `404` корня API не подтверждают вход в аккаунт и ответ модели. Сетевые результаты зависят от провайдера и времени проверки; физическая привязка исключает ложные выводы из перехваченных VPN/TUN запросов.

Целостность локальных ссылок, изображений и якорей Markdown проверяет `python tools/check_docs.py`; эта проверка включена в CI. Ссылки старых релизов на инструкции закреплены за соответствующими тегами.

VirusTotal привязан к точным хешам файлов. Смотрите [проверки безопасности](security/README.md); результаты старой версии не распространяются на новый установщик. Отсутствие обнаружений не является гарантией безопасности.
