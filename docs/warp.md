# GeoHide через WARP

Дополнительный режим разрабатываемой версии GeoRoute. Включается в **Настройки → WARP для GeoHide**. Базовый setup не включает туннель автоматически. Подписанный Wintun входит в пакет как файл и загружается только при включении WARP.

## Для пользователя

1. Нажмите **Установить компонент**. Загрузятся ядро и средство регистрации; подписанная DLL Wintun уже входит в пакет. Подтвердите один запрос администратора Windows.
2. Нажмите **Подключить WARP**. Первоначальный сохранённый маршрут — Gemini и проверка Google через EU GeoHide. Другой совместимый профиль можно выбрать в «Серверы» и нажать «Подключить».
3. При желании отметьте **Подключать автоматически при запуске Windows**. По умолчанию переключатель выключен. Он не включает соединение немедленно: для этого есть кнопка.
4. **Использовать WARP для кнопки подключения GeoHide** направляет главную кнопку и применение профиля через компонент. Этот переключатель не разрывает уже открытое соединение. Чтобы перейти обратно на обычные hosts, сначала отключите WARP.
5. Кнопка **Журнал** открывает локальные журналы. Удаление компонента находится рядом и требует администратора. Перед удалением основного приложения сначала удалите компонент.

Соединение поддерживается службой и не зависит от окна GeoRoute. Запуск самого приложения в трее настраивается отдельно. После ручного отключения служба не включает туннель сама до следующего запуска Windows с разрешённым автоподключением.

При подключении проверяется HTTPS; это не гарантия ответа модели для любого аккаунта. Если Google выдаёт CAPTCHA или ограничение страны, откройте Gemini сами и проверьте результат. `www.google.com` идёт через тот же GeoHide, что и Gemini; это влияет и на Google Поиск. `gemini.gstatic.com` остаётся на обычном маршруте Google.

## Что меняется в Windows

- Служба `GeoRouteWARP` от SYSTEM: контроллер запускается автоматически, соединение — только по отдельному разрешению пользователя.
- Программа: `%ProgramFiles%\GeoRoute WARP`. Конфигурация и ключи: `%ProgramData%\GeoRouteWarp\private`, доступ только SYSTEM и администраторам.
- Состояние и журналы без ключей: `%ProgramData%\GeoRouteWarp\public`. Запросы владельца: отдельная папка `requests`; служба принимает ограниченные JSON-данные, а не пути или команды.
- Адаптер `GeoRouteWARP`, точные временные IPv4-маршруты `/32` к адресам профиля и каталога GeoHide. При обновлении каталога мониторинг синхронизирует эти адреса. При конфликте существующего точного маршрута подключение отклоняется.
- Управляемый блок hosts с меткой `Transport: GeoRouteWARP`. Изменения записываются с проверкой исходного содержимого; отключение удаляет только собственный неизменённый блок. Внешние правки сохраняются.

Не устанавливаются маршруты по умолчанию, DNS-перехват, системный прокси или правила брандмауэра. Включение не выключает Happ или другие VPN. Существующие фильтры сторонних VPN всё равно могут влиять на передачу пакетов.

Служба проверяет свой процесс, маршруты и hosts локально каждые пять секунд, без HTTP-запросов. Проверка HTTPS выполняется при подключении и восстановлении. После сбоя пауза восстановления растёт от пяти секунд до пяти минут. Интервал сетевого мониторинга GeoRoute задаётся отдельно; по умолчанию два часа. WireGuard поддерживает туннель собственным keepalive.

При новом запуске Windows с выключенным автоподключением контроллер очищает остатки прерванного соединения и остаётся выключенным. Перезапуск контроллера в том же сеансе восстанавливает ранее включённое вручную соединение. Ключи и резервные данные при удалении компонента сохраняются с закрытыми правами; повторная установка без явного импорта создаёт новую регистрацию WARP.

## Зависимости и проверки

- [Mihomo v1.19.34](https://github.com/MetaCubeX/mihomo/releases/tag/v1.19.34), [исходники и GPL-3.0](https://github.com/MetaCubeX/mihomo/tree/v1.19.34).
- [Подписанный Wintun 0.14.1](https://www.wintun.net/); используется неизменённая DLL AMD64 с проверкой SHA-256 и подписи WireGuard LLC. Лицензия для готовой DLL отличается от лицензии исходников драйвера.
- [WARPSCOUT v0.16.1](https://github.com/vernette/warpscout/tree/v0.16.1), MIT. Только первоначальная регистрация и экспорт WARP, без стороннего регистрационного relay; затем вспомогательный EXE удаляется из установленной папки.

Все URL, версии и контрольные суммы находятся в [warp-runtime.json](../clients/windows/_service/warp-runtime.json). [Тексты лицензий](../clients/windows/_service/warp/licenses) устанавливаются вместе с компонентом. Бинарные файлы и личные ключи не хранятся в Git. Сборка добавляет неизменённую подписанную DLL Wintun после проверки SHA-256 и издателя; ядро Mihomo и WARPSCOUT в базовый архив не включаются. Старые VirusTotal-бейджи GeoRoute не относятся к этим загрузкам.

Проверки разработки: `clients/windows/tests/test_warp_manager.py` и `Test-Warp.ps1`; входят в общий `Run-Tests.ps1`. Они проверяют включение, раздельное автоподключение, сбои, сохранение внешних правок, ограничения профиля и маршрутов. Полная проверка после реальной перезагрузки Windows должна отмечаться отдельно: тесты логики её не заменяют.

Проверка установленного компонента 23 ноября 2026: установка, полное удаление и повторная установка компонента; подключение и отключение из обычной учётной записи, точное восстановление hosts, сохранение настройки автоподключения, восстановление после остановки собственного ядра и перезапуска службы в том же сеансе. В Chrome получен новый ответ Gemini через GeoHide EU, проверка Google прошла через тот же адрес. Эти результаты относятся к проверенному узлу и сети; Windows при проверке не перезагружалась.

Исправлены два сбоя, обнаруженных при установке: неверное чтение кода завершения вспомогательного процесса в Windows PowerShell 5.1 и ожидание унаследованных каналов вывода долгоживущего ядра. Добавлены проверки настоящих дочерних процессов, включая тайм-аут и удержание дескриптора вывода.

Проверена свежая регистрация WARP без импорта личного конфига и экспорт для Mihomo. На проверенном провайдере загрузка Wintun обрывалась после первых килобайт, поэтому готовые пакеты содержат DLL с закреплённым хешем и действительной подписью WireGuard LLC. Это не включает и не устанавливает службу автоматически.
