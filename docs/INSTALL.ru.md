# Как установить GeoRoute

## 1. Скачать

Откройте [готовые релизы](https://github.com/Georgy-hook/GeoRoute/releases/latest) и скачайте файл **GeoRoute-Windows-x64-0.3.1.zip** в разделе Assets. Архивы **Source code** предназначены для разработчиков.

## 2. Распаковать

Правой кнопкой по ZIP → **Извлечь всё**. Выберите постоянную папку, например `Документы\GeoRoute`. Приложению нужны все файлы внутри папки; не переносите только EXE отдельно и не запускайте его прямо из архива.

## 3. Запустить

Откройте **GeoRoute.exe**. Программа работает без отдельного установщика. Для мониторинга права администратора не нужны. Самостоятельно устанавливать Python/Java или вводить API-ключи не требуется.

Это сборка без коммерческой подписи издателя. Контрольная сумма ZIP опубликована рядом с архивом, исходный код — в репозитории. Отключать защиту Windows для работы приложения не требуется.

## 4. Выбрать маршрут

Подождите первую проверку. При недоступных узлах она может занять несколько минут; в «Мониторинге» виден прогресс, а повторный запуск временно недоступен. Откройте **Серверы**. Карточка показывает, можно ли подключить профиль и какой узел мешает. Недоступные маршруты нельзя выбрать. Если есть доступный регион, выберите его; US+EU доступен только при работающих узлах обоих регионов.

**US+EU** направляет ChatGPT через США, а Gemini и известные адреса вложений через Европу. Для одного Gemini выберите **Gemini — EU** или **Gemini — US**; доступность ChatGPT на эти карточки не влияет. **US**, **EU**, **RU** — отдельные региональные профили GeoHide. Регион в названии — группа провайдера; фактическая страна выхода показана в мониторинге.

## 5. Подключить

Вернитесь на **Подключение** и нажмите **Включить**. Подтвердите системный запрос Windows от своего пользователя — это нужно для изменения `hosts`. Дождитесь результата. Та же кнопка **Выключить** убирает управляемое подключение.

В разделе «Серверы» также есть кнопка подключения выбранного профиля. Для ручного US/EU откройте **Мониторинг → Адреса US + EU → Вручную**, выберите или впишите оба IP и нажмите **Сохранить и подключить**. Новый IP сначала сохраните без подключения и проверьте кнопкой «Проверить серверы».

## Как обновляются адреса

Программа обновляет списки RU/US/EU раз в час, а сетевые проверки — каждые две минуты. Не нужно скачивать новый релиз только из-за смены IP. Ручные узлы сохраняются отдельно. Автовыбор обновляет сохранённые профили; изменение активного подключения требует кнопки и подтверждения Windows. Если нужного сервера нет, программа пишет причину, а не показывает фиктивный успех.

## После перезагрузки

Применённые записи hosts сохраняются. Для фоновых проверок включите **Настройки → Открывать GeoRoute в трее при входе в Windows**. Это запускает менеджер, а не скрытно подключает новый маршрут. Обычное закрытие окна сворачивает его в трей; полный выход доступен в настройках и меню значка.

## Обновить саму программу

Сначала выйдите из GeoRoute через настройки или значок в трее. Распакуйте новую версию во временную папку, затем замените файлы в старой папке. Сохраните свои `_service/profiles.json`, папку `_service/profiles` и `_service/connection-routes.json`, чтобы не потерять импортированные профили. Личные настройки `geohide-settings.json`, история и резервные копии не входят в архив и остаются на месте. Не удаляйте старую папку целиком, если хотите сохранить их. Переход с имени NextDNS поддерживается совместимым `NextDNS.exe`; основной запуск теперь **GeoRoute.exe**.

## Удалить

Нажмите **Выключить** и подтвердите Windows. В настройках снимите запуск при входе в Windows, выйдите из приложения, затем удалите его папку. Если вы отдельно включали NextDNS Bridge или HTTP-прокси, сначала отключите эти дополнительные режимы соответствующими инструментами. Обычный режим GeoRoute их не устанавливает.

## Что означает статус

- **Выключено** — управляемое подключение отсутствует; это нормальное состояние.
- **Проверяю серверы** — актуального результата ещё нет.
- **Включено** — адреса применены, необходимые узлы прошли актуальную сетевую проверку.
- **Подключено · проверка Google** — сервер Gemini отвечает, но Google просит CAPTCHA. Откройте Gemini в браузере и пройдите проверку самостоятельно.
- **Сервер недоступен** — конкретный узел не прошёл проверку; подробности находятся в разделе серверов.

Проверка HTTPS не заменяет вход в ChatGPT и открытие конкретного вложения. Помощь с DNS-кешем и GIF/ZIP находится на отдельном экране и объясняет назначение каждого действия.
