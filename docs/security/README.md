# Проверки безопасности

- [GeoRoute 0.4.1: VirusTotal, даты, охват и хеши](virustotal-v0.4.1.md).
- Исторические срабатывания 0.4.0 и промежуточные эксперименты доступны в [архиве тега v0.4.1](https://github.com/Georgy-hook/GeoRoute/tree/v0.4.1/docs/security). Подробные одноразовые отчёты удалены из текущего дерева; история не переписывалась.

Срабатывания первоначальной версии локализованы на собственных EXE-обёртках; конкретное внутреннее правило антивирусов неизвестно. GUI запускается системным PowerShell, Bridge работает напрямую в Python. Обычный Setup строится Inno Setup и проверяется отдельно от ZIP.

Сверяйте SHA-256 и дату анализа: результаты одной версии не распространяются на другую. Неподдерживаемые форматы, ошибки и тайм-ауты не являются успешными проверками. Антивирус и проверки TLS приложение не отключает.
