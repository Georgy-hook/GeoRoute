## Происхождение и ограничения

- Публикуются точные файлы из [Windows build + VirusTotal, run 42494096217](https://github.com/Georgy-hook/GeoRoute/actions/runs/42494096217), исходный код пакета — `b169828f2521adaabe990591df541b601a134e4e`. После анализа файлы не пересобирались и не перепаковывались. Последующие изменения релизной ветки касаются документации.
- Сверены SHA-256 MSI, ZIP и всех четырнадцати выбранных членов ZIP с отчётом и манифестом сборки. Персональные профили, журналы, токены и cookies в отправленные пакеты не входили.
- Дополнительно к прежнему охвату проверены исходники службы выборочного DNS, её настройки/включение и оба новых окна: `selective_dns.py`, `dns_monitor.py`, `SelectiveDns.ps1`, `SelectiveDnsSetup.ps1`, `DnsSitesUI.ps1`, `DnsMonitorUI.ps1`.
- Неизменившиеся компоненты используют существующие отчёты с исходной датой анализа. Ноль обнаружений не означает, что все движки поддерживают формат или что все файлы внутри архива проверены отдельно. Остальные DLL, ресурсы и wheel-файлы отдельно не отправлялись.
- Windows CI проверил установку, обновление, сохранение профилей/списка сайтов/выбранного DNS, запуск GUI и удаление этих пакетов. DNS-мониторинг дополнительно запущен из точного ZIP со встроенным Python: все 16 провайдеров получили завершённые результаты, выбор свежего отвечающего DNS доступен, сетевые настройки не менялись. Это проверка DNS-транспорта, а не доступности всех сервисов. [Пределы функциональных проверок](../VERIFICATION.md).
- MSI использует штатный Windows Installer. Собственных EXE-обёрток GUI/Bridge в поставке нет; Python включён с лицензией и проверкой целостности. Установщик не подписан сертификатом издателя.
