# VirusTotal — GeoRoute 0.6.0 для Windows

Снимок 28.11.2026: у MSI, ZIP и 32 выбранных компонентов **0 отметок `malicious` и 0 `suspicious`**. У MSI — 58 ответов `undetected`, 1 тайм-аут и 9 неподдерживаемых проверок; у ZIP — 62, 1 и 5 соответственно. Тайм-аут и неподдерживаемый формат не являются успешной проверкой. Это результаты для конкретных байтов, а не гарантия безопасности.

Исходный коммит: [`019cc063`](https://github.com/Georgy-hook/GeoRoute/commit/019cc0638e15a4d06e0f82daf32cf4ac97ca3275). Для VirusTotal использовали файлы **из того же запуска**. Последующие изменения документации не требуют пересборки этих пакетов.

## Границы проверки

- В список отдельных файлов входят главный экран, обработчики выбора маршрута, служба WARP и включённая DLL Wintun. Сборка проверяет SHA-256 и подпись драйвера. Это не подпись MSI: установщик не подписан сертификатом издателя.
- Остальные файлы внутри поставки не отправлялись по отдельности. Загружаемые после согласия необязательные компоненты, пользовательская регистрация, профили пользователей и журналы не входили в этот аудит.
- Установка в Windows и ответы по HTTPS не доказывают ответ модели Gemini после входа на конкретном провайдере. [Функциональные проверки](../VERIFICATION.md) · [Изменения и ограничения 0.6.0](../releases/v0.6.0.md).
- [Отчёт стабильной 0.5.0](https://github.com/Georgy-hook/GeoRoute/blob/v0.5.0/docs/security/README.md) и [отчёт заменённого кандидата от 22 ноября](https://github.com/Georgy-hook/GeoRoute/blob/c12da6bd873ab9f427385e25ae2e10cb3145e063/docs/security/v0.6.0.md) относятся к другим файлам.
