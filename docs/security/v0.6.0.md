## Охват и границы

- Помимо MSI/ZIP отдельно проверены 20 перечисленных компонентов, включая код состояния кнопок мониторинга, выбора узла, проверок Gemini, миграции и выборочного DNS. Остальные библиотеки, ресурсы и скрипты не отправлялись по отдельности; не следует называть это независимой проверкой каждого файла.
- MSI установлен, обновлён, запущен и удалён в одноразовой Windows CI. Проверены сохранение настроек/профилей/сайтов, блокировка замены запущенного приложения и отсутствие сетевых изменений. Миграция старого каталога проверена отдельно, включая потерянную старым импортом отметку версии.
- MSI использует Windows Installer; собственных EXE-обёрток GUI/Bridge нет. Встроенный Python поставляется с лицензией и проверкой целостности. Сертификата подписи издателя у установщика нет.
- Тесты не подтверждают ответ Gemini после входа, работу конкретной GIF/MP4 или отсутствие блокировок у провайдера. [Функциональные проверки](../VERIFICATION.md), [статус 0.6.0](../releases/v0.6.0.md).
