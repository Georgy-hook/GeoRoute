## Какие гипотезы проверены

- Переписывание управления процессом Bridge убрало обнаружение Elastic в проверенном кандидате, но сохранило два других. Из нескольких изменений нельзя выделить единственный вызов как установленную причину.
- Устранение собственного C# service-host и размещение DNS-кода непосредственно в процессе Python дало пакет Bridge без обнаружений. Проверены весь пакет и скрипт отдельно. Сохранились проверка TLS, DNS-протокол и запуск службы под LocalService. SCM-проверки в отдельной Windows VM подтвердили запуск, остановку, перезапуск, диагностику занятого порта и последующий запуск.
- Смена компилятора launcher при неизменном C# исходнике **не устранила** обнаружения Bkav/APEX. Поэтому причиной нельзя уверенно назвать старый компилятор или одну лишь случайную пересборку.
- Удаление встроенного PowerShell из C# launcher тоже не обеспечило отсутствие обнаружений: APEX перестал отмечать тот кандидат, CrowdStrike начал. Этот результат не доказывает отсутствие проблемы у клиента целиком.
- Нативная Win32 обёртка тоже получила две отметки, несмотря на 0/71 у её ZIP. Убрана сама необходимость собственного launcher EXE: системный PowerShell открывает тот же WPF GUI, который управляет своей единственной копией и треем. Финальный пакет, CMD и код интерфейса проверены отдельно без обнаружений.
- Суффикс Bkav `B4FA2B78` совпадает с CRC32 исходного launcher, `A297B9E3` — с CRC32 SDK-варианта; в CLI-варианте `CF5E789` соответствует CRC32 без ведущего нуля. Суффикс McAfeeD совпадает с началом SHA-256 соответствующего Bridge. Эти метки идентифицируют файлы, но не раскрывают внутренние признаки классификации.

## Ограничения вывода

Данные локализуют обнаружения до конкретных собственных EXE и показывают результат изменения архитектуры. Они **не устанавливают точное внутреннее правило** каждого закрытого движка. Ни неподписанный файл, ни `ExecutionPolicy Bypass`, ни `Process.Start` по отдельности не доказаны как единственная причина.

Числитель таблицы — `malicious`, знаменатель — количество результатов движков. У промежуточных кандидатов `suspicious = 0`. Для прямого пакета Bridge: 63 `undetected`, 1 timeout, 7 unsupported; для bridge.py: 58 `undetected`, 13 unsupported. У Python использован существующий отчёт от 31.10.2026. Отсутствие обнаружений не является сертификатом безопасности, а подпись и репутация — отдельные вопросы.

Служба использует [стандартные SCM API Microsoft](https://learn.microsoft.com/en-us/windows/win32/api/winsvc/nf-winsvc-registerservicectrlhandlerexw). [Формат результатов VirusTotal](https://docs.virustotal.com/reference/analyses-object) описывает вердикты, но не предоставляет внутреннее объяснение решений этих моделей.
