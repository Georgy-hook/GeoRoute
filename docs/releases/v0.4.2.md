# GeoRoute 0.4.2 — обычная установка Windows

**Для установки скачайте GeoRoute-Setup-0.4.2-x64.msi.** Откройте файл → «Далее» → «Установить». После завершения откройте ярлык GeoRoute на рабочем столе или в меню «Пуск».

Приложение устанавливается для текущего пользователя. Python отдельно не нужен. Подключение включается кнопкой в самом GeoRoute и отдельным подтверждением Windows.

- При обновлении сохраняются профили, выбранные адреса, настройки и журналы. Перед обновлением выйдите из GeoRoute через трей.
- Для удаления сначала выключите подключение в приложении, затем используйте «Параметры Windows → Приложения → GeoRoute». Личные данные сохраняются в папке приложения.
- ZIP остался дополнительным вариантом без установки. Его настройки хранятся отдельно; автоматического переноса между ZIP и MSI нет.
- Удалены устаревшие отчёты о состоянии конкретного компьютера и одноразовые инструменты экспериментов. Полезные проверки и архивные результаты доступны по ссылкам.

**VirusTotal: ноль обнаружений** у итогового MSI и ZIP. У MSI 55 ответов `undetected`, два тайм-аута, две ошибки и 12 неподдерживаемых проверок; отсутствие обнаружений не гарантирует безопасность. Публикуются точные проверенные файлы без пересборки.
