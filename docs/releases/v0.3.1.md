# GeoRoute 0.3.1

Добавлена кнопка **?** рядом с «Добавить сервер» и в окне импорта. Она открывает понятную пошаговую инструкцию внутри приложения: где взять файл, как его добавить, выбрать и включить. Справка работает без интернета.

В README добавлены технический формат `.hosts`, пример, допустимые домены и ограничения. Выбор файла теперь соответствует импорту: `.hosts` размером до 1 МиБ.

Скачайте **GeoRoute-Windows-x64-0.3.1.zip**, распакуйте всю папку и откройте **GeoRoute.exe**. Для обновления сохраните свои профили и настройки, как описано в [инструкции](https://github.com/Georgy-hook/GeoRoute/blob/v0.3.1/docs/INSTALL.ru.md). Импорт профиля сам по себе не включает подключение.
