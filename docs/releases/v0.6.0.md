## Как пользоваться

**Мониторинг → Серверы GeoHide → Проверить серверы → Подключить** в строке нужного узла → подтвердите Windows. Кнопка недоступна во время проверки и при отсутствии свежего успешного результата обязательных проверок. Узел должен поддерживать ChatGPT и вложения; ограничения Gemini показываются отдельно. Выбранный узел появляется в «Серверы», повторный выбор обновляет ту же карточку. Если запрос Windows отменён, профиль сохранён, но подключение не считается изменённым.

Для других DNS: **Мониторинг → DNS-провайдеры → Проверить все DNS → выбрать отвечающий → Настроить этот DNS…**. Добавьте сайты и включите их маршрут отдельной кнопкой. Остальные сайты остаются на прежнем DNS. DNS-IP нельзя без проверки использовать как адрес HTTPS-прокси в hosts.

В **Настройки → Автопроверка серверов** выберите интервал. «Никогда» отключает проверки и при запуске; ручные проверки доступны всегда. Автоподбор обновляет подготовленные профили, а применение в Windows требует явного подключения и UAC.

## Сетевой снимок 22 ноября

В ограниченной проверке из одного подключения ни один из семи EU и четырёх US кандидатов не подтвердил HTTPS Gemini: преимущественно тайм-аут TCP, у одного узла TCP отвечал, но TLS не завершился. Обычный Google frontend при этом вернул HTTP 200. VPN/hosts/DNS не переключались. Это локальный результат с короткими тайм-аутами, а не доказательство глобального закрытия US/EU или точной причины блокировки. Недоступность до TLS не исправляется добавлением домена в hosts.

## Что ещё не подтверждено

Общий IP Gemini и `www.google.com` остаётся необходимым для проверки Google. `www.google.com` обслуживает также Google Поиск. Статические ресурсы `gemini.gstatic.com` остаются на Google. Одна правка hosts не снимает блокировку сервера провайдером, репутационное ограничение общего IP или ограничение аккаунта Google. Для всех EU-узлов успешная работа Gemini не заявляется.

Ответы мониторинга относятся к условиям проверки. Включённый VPN/TUN может влиять на результат даже при привязке к физическому IPv4-интерфейсу. После смены сети повторите проверку. HTTPS страницы, API и корня хранилища не доказывает ответ модели или скачивание конкретной GIF.

## Дополнительный режим WARP

Добавлены необязательная служба, управление подключением из настроек и независимый переключатель автоподключения (по умолчанию выключен). Маршруты ограничены точными IP GeoHide, без смены общего DNS и маршрута интернета. Журналы доступны из карточки WARP. Ядро и средство регистрации скачиваются по закреплённым версиям и SHA-256. Подписанная DLL Wintun включена в пакет, чтобы установка не зависела от доступности сайта драйвера. Проверка реального перезапуска Windows остаётся отдельным этапом и не подменяется тестами логики. Подробнее: [WARP](../warp.md).

## Portable и обучение

- На главной есть переход к серверам и встроенная инструкция из четырёх шагов. Она открывается по запросу и не включает сеть сама.
- Уменьшены декоративные элементы, упрощены фоны и карточки настроек. Главное действие и текущее состояние сохранены.
- В ZIP включены Python и библиотеки. WARP остаётся отдельной установкой с правами администратора.
- Сборка принимает отдельную папку вывода, чтобы подготовка portable не заменяла ранее проверенные релизные файлы.

## Проверка службы WARP

На установленной службе проверены подключение/отключение без повторного UAC, восстановление исходного hosts, сохранение переключателя автоподключения, автоматическое восстановление после сбоя ядра и перезапуска службы. В обычном Chrome получен новый ответ Gemini. Исправлены запуск вспомогательных процессов и зависание на унаследованных каналах вывода. Перезагрузка Windows остаётся отдельной проверкой; её результаты не заявляются.
