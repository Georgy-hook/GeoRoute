# GeoRoute 0.4.3 — ChatGPT и Gemini через общий GeoHide

**[Скачать установщик для Windows](https://github.com/Georgy-hook/GeoRoute/releases/download/v0.4.3/GeoRoute-Setup-0.4.3-x64.msi)**

Откройте MSI → **Далее → Установить**, затем запустите GeoRoute с ярлыка. В приложении дождитесь проверки серверов, выберите доступный профиль и нажмите **Включить**. Python отдельно устанавливать не нужно.

## Что изменилось

- Общие профили GeoHide для ChatGPT, Gemini и вложений OpenAI: EU основной/запасной, US основной/запасной, RU и смешанный US + EU.
- Gemini и проверка Google идут через один адрес. Мониторинг проверяет общий HTTP/2-маршрут, показывает ограничения Gemini отдельно и подбирает доступный резерв по задержке.
- Подтверждённый рабочий EU-адрес стал начальным основным узлом. Адреса обновляются по свежим проверкам; работа на каждом EU-сервере не гарантируется.
- Добавление профиля по IP упрощено: страна и необязательное название, без отдельного выбора ChatGPT/Gemini.
- Устаревшие встроенные Gemini US/EU и «Вложения 25.10» убраны с резервной копией каталога. Остальные пользовательские профили сохраняются.
- Восстановление NextDNS Bridge проверяет DNS независимо от правил GeoHide; исправлена диагностика hosts.

## Обновление

Выйдите из GeoRoute через значок в трее → **Выход**, затем запустите новый MSI. Профили, настройки и журналы сохраняются. Установка сама не меняет сеть; подключение требует отдельного действия в приложении и подтверждения Windows.

ZIP — дополнительный вариант без установки: извлеките всю папку и запустите `GeoRoute.cmd`. Данные ZIP и MSI хранятся отдельно.

## Gemini

Happ для этого маршрута не требуется. После запуска Chrome сначала откройте Gemini. Точный `www.google.com` также обслуживает Google Поиск: его маршрут меняется вместе с проверкой Gemini. Gmail и остальные Google-сервисы целиком не перенаправляются.

Зелёная проверка подтверждает сетевой маршрут, а не вход в аккаунт или ответ модели. Основной EU-маршрут дополнительно проверен ответом Gemini пользователем; доступность и скорость других узлов могут отличаться. Автоподбор обновляет подготовленные профили; применение нового адреса выполняется кнопкой подключения.
