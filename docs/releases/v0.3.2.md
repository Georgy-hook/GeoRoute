# GeoRoute 0.3.2

Теперь профиль можно создать прямо в приложении: **Серверы → Добавить сервер → По IP-адресу**. Укажите IP совместимого сервера, сервис ChatGPT или Gemini и страну, затем нажмите **Сохранить профиль**. Название необязательно.

GeoRoute сам подготовит нужные домены и добавит карточку. Для ChatGPT включены также известные адреса вложений. Сохранение не переключает подключение: выберите созданную карточку и нажмите «Включить» на главной. Проверка доступности сервера выполняется отдельно; выбор страны задаёт флаг и подпись.

Импорт `.hosts` сохранён во вкладке **Из файла**. Инструкция по кнопке **?** и README обновлены.

Скачайте **GeoRoute-Windows-x64-0.3.2.zip**, распакуйте всю папку и запустите **GeoRoute.exe**. При обновлении сохраните свои профили и настройки по [инструкции](https://github.com/Georgy-hook/GeoRoute/blob/main/docs/INSTALL.ru.md).
