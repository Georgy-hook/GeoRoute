# GeoRoute 0.5.0 — GeoHide DNS, свои сайты и удобный мониторинг

**[Скачать установщик для Windows](https://github.com/Georgy-hook/GeoRoute/releases/download/v0.5.0/GeoRoute-Setup-0.5.0-x64.msi)**

Откройте MSI → **Далее → Установить**, затем запустите GeoRoute с ярлыка. Отдельно устанавливать Python или Java не нужно.

## Новое

- **Другие сайты через GeoHide DNS.** В «Серверы → Сайты и DNS» выберите GeoHide EU/US/RU, альтернативный или свой HTTPS DoH. Добавляйте сайты из каталога или свои домены/ссылки. Только выбранные имена идут через этот DNS; остальные запросы сохраняют прежний маршрут.
- **Мониторинг DNS-провайдеров.** Отдельная вкладка рядом с серверами: загрузка каждой строки, задержка, проверенные IP, время, поиск и причины отказа. Отвечающие DNS идут первыми. Кнопка «Использовать DNS…» переносит свежий результат в окно сайтов; включение выполняется отдельно.
- **Адаптивные таблицы.** Мониторинг заполняет доступное окно; на большом экране видно больше строк и столбцов. На небольшом остаются прокрутка и закреплённый первый столбец. Ручные настройки свёрнуты под списком серверов.
- **Сохранение режима DNS.** Отдельная служба с автозапуском, восстановлением после сбоя и обновлением адресов того же провайдера. Применение проверяет сертификаты, DNS и конфликты с hosts/чужими политиками; при ошибке выполняется откат.

## Как начать и обновиться

Для ChatGPT/Gemini дождитесь проверки в «Серверы», выберите доступный профиль и нажмите «Включить» на главной. Для других сайтов: **Мониторинг → DNS-провайдеры → выбрать отвечающий → Использовать DNS… → добавить сайты → Включить / обновить** и подтвердить Windows.

Для обновления выйдите через значок GeoRoute в трее → **Выход**, затем запустите новый MSI. Профили, настройки и журналы сохраняются. Установка сама не меняет сеть. ZIP остаётся дополнительным вариантом: извлеките всю папку и откройте `GeoRoute.cmd`; данные ZIP и MSI автоматически не объединяются.

Главная кнопка управляет hosts-профилем ChatGPT/Gemini. Дополнительный DNS сайтов включается и выключается в своём окне, его состояние видно на главной. Перед удалением отключите оба режима, если они были включены.

Ответ DNS не обещает поддержку любого сайта. Провайдеры поддерживают разные сервисы; приложения с собственным Secure DNS могут обходить настройки Windows. Проверка DNS отправляет только `example.com`, не список ваших сайтов. Сертификаты HTTPS проверяются штатно.
