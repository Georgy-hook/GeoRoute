# GeoRoute 0.4.1

GUI сохраняется; новый файл запуска — **GeoRoute.cmd**. Собственные EXE-обёртки клиента и службы убраны, интерфейс использует системный PowerShell, а необязательный Bridge работает прямо в изолированном Python под LocalService. Сохраняются одна копия окна, трей, профили и перенос собственного включённого автозапуска.

Bridge закрывает активные соединения при остановке, сообщает состояние Windows SCM и не записывает устаревшие boot-проверки после завершения. Реальная временная служба проверена в отдельной Windows VM: запуск, остановка, перезапуск, отказ при занятом порте и восстановление. Системные DNS/hosts пользователя не менялись.

**VirusTotal: 0 обнаружений** у точного ZIP, GeoRoute.cmd, GUI, модуля активации, bridge.py и Python. Часть движков сообщает неподдерживаемый тип, ошибки или тайм-ауты; это не сертификат безопасности. [Полные отчёты, даты, охват и SHA-256](https://github.com/Georgy-hook/GeoRoute/blob/main/docs/security/virustotal-v0.4.1.md). [Отчёт архива](https://www.virustotal.com/gui/file/538bfd94aaf31136a298f74ac531b0c16c1878138acf80f2c1ea134e98b8fbde/detection).

Скачайте **GeoRoute-Windows-x64-0.4.1.zip**, извлеките всю папку и откройте GeoRoute.cmd. При обновлении завершите прежнюю версию через трей и замените ярлык, указывающий на старый EXE, ярлыком на GeoRoute.cmd. Профили и настройки сохраняйте; новое подключение не включается автоматически. Если использовалась отдельно установленная служба NextDNS, её миграция выполняется явной установкой/восстановлением Bridge с подтверждением Windows.
