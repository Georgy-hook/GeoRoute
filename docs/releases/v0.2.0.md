# GeoRoute 0.2.0

Первый релиз приложения под именем **GeoRoute** — простой Windows-клиент для маршрутов GeoHide.

## Скачать и запустить

1. Скачайте **GeoRoute-Windows-x64-0.2.0.zip** ниже, а не архив Source code.
2. Правой кнопкой по ZIP → **Извлечь всё**. Сохраните всю папку.
3. Запустите **GeoRoute.exe**. Дождитесь проверки, выберите доступный маршрут в «Серверы».
4. На главном экране нажмите **Включить** и подтвердите запрос Windows.

[Полная инструкция](https://github.com/Georgy-hook/GeoRoute/blob/main/docs/INSTALL.ru.md) · [Описание приложения](https://github.com/Georgy-hook/GeoRoute#readme)

Нужны Windows 10/11 x64, Windows PowerShell 5.1 и .NET Framework 4.8. Python/Java устанавливать не требуется. Для обычного hosts-режима не нужны аккаунт NextDNS и API-ключи.

## Что изменилось

- Главный экран с одной кнопкой включения/выключения. Серверы, помощь, журнал и настройки находятся отдельно.
- Обновление списков и замена адресов работают для US, EU и RU независимо. Рабочий US не меняется из-за отказа EU; для вложений выбирается другой доступный EU.
- Недоступные, удалённые из источника и давно не проверенные узлы блокируют подключение управляемого профиля. Карточка показывает конкретную причину.
- Мониторинг с флагами, страной выхода, задержками, фильтрами и историей 24 реальных проверок.
- Исправлено постоянное предупреждение NextDNS в обычном hosts-режиме: выключенное подключение теперь нормальное состояние; рабочие узлы получают положительный статус.
- Ручные адреса сохраняются при обновлении источников. Автовыбор обновляет профили, а применение в Windows остаётся явным действием с подтверждением.

## Перед использованием

GeoRoute — независимый клиент серверов GeoHide, а не VPN для всего интернета. Серверы могут быть недоступны с конкретного подключения. Зелёная сетевая проверка не подтверждает вход в ChatGPT, скачивание конкретного файла или работу управления компьютером. Применённые настройки сохраняются после перезагрузки; полный выход останавливает мониторинг.

Сборка не имеет коммерческой подписи издателя. Рядом с ZIP опубликован SHA-256, исходники и проверки доступны в репозитории. Не требуется отключать защиту Windows.

Для обновления выйдите из прежнего приложения и замените файлы в его папке, сохранив настройки и резервные копии. Старые ярлыки NextDNS.exe совместимы; основной EXE теперь GeoRoute.exe.
