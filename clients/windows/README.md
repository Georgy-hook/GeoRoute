# GeoRoute для Windows

Скачайте **GeoRoute-Setup-0.4.2-x64.exe** из [последнего релиза](https://github.com/Georgy-hook/GeoRoute/releases/latest), нажмите **Далее → Установить** и откройте ярлык **GeoRoute**. Выберите доступный маршрут и нажмите **Включить**.

[Установка и удаление](../../docs/INSTALL.ru.md) · [Проверки CI](../../docs/VERIFICATION.md) · [VirusTotal](../../docs/security/README.md) · [Сборка](../../docs/DEVELOPMENT.md).

Дополнительный ZIP предназначен для запуска без установки: распакуйте всю папку и откройте `GeoRoute.cmd`. Это тот же GUI. Настройки установленной и ZIP-версии автоматически не объединяются.
