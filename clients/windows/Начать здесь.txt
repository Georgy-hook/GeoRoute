GeoRoute · portable 0.6.0

КАК ЗАПУСТИТЬ
1. Правой кнопкой по ZIP → «Извлечь всё».
2. Сохраните всю папку в удобном постоянном месте.
3. Откройте GeoRoute.cmd. Устанавливать Python и Java отдельно не нужно.

На главной есть «Как настроить GeoRoute»: четыре коротких шага
про запуск, выбор сервера, WARP и свои сайты.

КАК ПОДКЛЮЧИТЬСЯ
На главной нажмите «Подключиться». GeoRoute проверит выбранный
сервер напрямую. Если он ответит, подтвердите запрос Windows
на применение профиля и дождитесь надписи «Подключено напрямую».

ЕСЛИ СЕРВЕР НЕ ОТВЕТИЛ
Когда интернет доступен, главная предложит повторить напрямую или
попробовать тот же сервер через WARP. Установка начнётся только
после вашего согласия. При отказе сервиса маршрут не переключается.
Ручное управление и журналы: «Дополнительно».
Подписанный файл Wintun включён в архив, но без включения WARP не загружается.
Ядро и средство регистрации скачиваются при установке компонента.
Дополнительный компонент устанавливается отдельно с правами
администратора. Это уже системная служба, даже при запуске из ZIP.
Подключение и автоподключение включаются по вашему выбору.
Автоподключение WARP и запуск окна в трее — разные настройки.

ДРУГИЕ САЙТЫ
«Серверы → Сайты и DNS»: выберите DNS и добавьте сайты.
Этот режим включается отдельно, остальные запросы идут через
прежний DNS. GeoHide поддерживает не все сайты.

ОТКЛЮЧЕНИЕ И УДАЛЕНИЕ
Кнопка на главной выключает основное подключение.
Закрытие окна сворачивает GeoRoute в трей и не отключает маршрут.
Перед удалением папки выключите подключение и DNS для сайтов,
при необходимости выберите «Дополнительно → Удалить компонент WARP», затем выйдите через трей.
Если включали запуск GeoRoute с Windows, выключите и его.

ОБНОВЛЕНИЕ
Сначала выберите «Выход» в трее. Распакуйте новую версию отдельно.
Сохраните старую папку с профилями и настройками до переноса.
ZIP и Setup используют разные папки; автоматического переноса нет.

Нужны Windows 10/11 x64, Windows PowerShell 5.1 и .NET Framework 4.8.
Для проверки ZIP сравните его SHA-256 с файлом .sha256 на странице
релиза. Отчёты от старых сборок к этому файлу не относятся.
